OCTOBER SHIFT - PROJECT NOTES Last updated: August 17, 2026

CURRENT STATUS

October Shift is ready to push and deploy as a WORK IN PROGRESS.

Do not start over next time.

It is now a live 2026 MLB contender-ranking dashboard with
starting-rotation scoring, bullpen scoring, ranking history, movement
tracking, team/player images, and a one-command update pipeline.

IMPORTANT: October Shift is NOT a World Series probability model. The
score is a relative contender rating.

CURRENT FORMULA

Starting Rotation: 20% Bullpen: 5% Run Differential: 20% Post-All-Star
Performance: 20% Last 10 Games: 15% Quality-Adjusted Performance: 10%
Overall Record: 10% TOTAL: 100%

Do not keep changing the weights just because one team looks too high or
too low.

WHAT IS WORKING

1.  GAME DATA

-   fetch_data.py pulls completed 2026 MLB games.
-   Dashboard was updated through August 17 during today’s work.
-   Latest dashboard showed 1,870 completed games and all 30 teams.

2.  STARTING PITCHING

-   Statcast pitching data is pulled.
-   Starting pitchers are identified.
-   Starter run scores are built.
-   A projected four-man postseason rotation is built for each team.
-   Rotation scoring includes ace strength, top-three quality, top-four
    quality and depth.
-   Workload/reliability rules help keep openers and tiny samples from
    being treated like established aces.
-   Pitcher headshots show in the dashboard.

3.  BULLPEN MODEL This is BUILT. Old notes saying bullpen scoring still
    needs to be added are outdated.

The bullpen pipeline now includes: - bullpen appearances -
inherited-runner entries - play-by-play - inherited-runner scoring -
reliever outs - reliever run-prevention scores - team bullpen scores

Outputs include bullpen rank, best reliever, top-three and top-five run
prevention, qualified relievers, inherited-runner results, strand rate
and neutral bullpen score.

Bullpen is intentionally 5% of the overall contender score right now.

4.  CONTENDER BOARD

-   build_contender_board.py works.
-   All 30 teams receive an October Shift score.
-   Starting rotation and bullpen are separate components.
-   contender_scores_2026.csv is the main board used by the app.

5.  RANKING HISTORY + MOVEMENT

-   save_ranking_history.py works.
-   ranking_history_2026.csv stores snapshots.
-   Movement page compares the latest two dates.
-   It can show biggest riser, biggest faller, largest score gain, most
    stable team, rank change and score change.
-   If there is no rank movement, say so. Do not manufacture movement.

6.  STREAMLIT DASHBOARD Pages:

-   Home
-   Rankings
-   Teams
-   Rotations
-   Bullpens
-   Movement
-   Model

Current look: - light blue / red / white - MLB team logos -

We tried custom pitcher-arm and bull PNG icons on the Model page and

DO NOT FORGET

-   Original single-game model was not very strong. That is okay.
-   Recent team form + run differential was one of the better simple
    game-model ideas tested.
-   Adding pitching did NOT consistently improve individual-game
    prediction.
-   Failed experiments explain why the project changed direction.
-   Pitching is useful as part of a postseason contender profile.
-   Rotation score rewards several strong starters, not only one ace.
-   Rotation score is a ceiling, not a health/availability guarantee.
-   Bullpen strength is now separate.
-   Inherited runners matter.
-   Small samples should not take over a pitching ranking.
-   October Shift is a contender ranking, not a guaranteed prediction.
-   Do not change weights every time a ranking feels surprising.
-   Movement needs multiple meaningful snapshots before it becomes
    visually interesting.
